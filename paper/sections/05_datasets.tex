\section{Datasets}
\label{sec:datasets}

The repository registry covers MetroPT, MetroPT2, SCANIA Component X, Hydraulic Systems, and SECOM. MetroPT contains air-production-unit telemetry from an urban metro setting with pressure, temperature, current, digital control signals, and documented maintenance/failure intervals \citep{Veloso2022MetroPT}. MetroPT2 provides a benchmark replication release with documented failure periods \citep{MetroPT2Zenodo2023}. SCANIA Component X is a fleet-level dataset containing anonymized operational variables, repair records, and truck specifications for a proprietary component \citep{Kharazian2025Scania}. Hydraulic Systems adds cycle-level component-condition measurements from an experimental hydraulic test rig \citep{Helwig2018HydraulicSystems}. SECOM adds high-dimensional semiconductor process measurements with pass/fail yield labels \citep{McCann2008SECOM}.

The paper assets used in this manuscript are built from cached processed data and public acquisition metadata. Industrial limitations are material to interpretation. MetroPT-style telemetry can have many samples but few independent failure intervals. MetroPT2 is valuable as a temporal replication resource, but replication still depends on comparable labels and preprocessing. SCANIA changes the independence unit to vehicles and repairs, Hydraulic Systems changes it to load cycles, and SECOM changes it to production examples. Transfer claims must therefore match the dataset-specific estimand. The current generated claim ledger blocks a positive population-level superiority claim for industrial predictive maintenance; this limitation is recorded as CLM-007.
