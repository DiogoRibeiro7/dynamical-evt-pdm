# Contributing

1. Open an issue describing the research or engineering change.
2. State which hypothesis, estimand or reproducibility requirement it affects.
3. Add or update tests before changing public behaviour.
4. Run `make check`.
5. Do not commit raw datasets, generated artifacts or credentials.
6. Separate exploratory methods from methods used in confirmatory tables.
7. Update `docs/statistical_claims.md` when a change affects interpretation.
