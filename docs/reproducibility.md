# Reproducibility requirements

Every reported result must be generated by a configuration-controlled command.

## Experiment record

Persist:

- Git commit hash;
- configuration file and its SHA-256 digest;
- random seeds;
- dataset manifest and checksums;
- package lock file;
- runtime environment;
- fitted threshold and regime parameters;
- metric definitions and matching tolerances;
- generated figures and tables.

## Determinism

- Seed NumPy and scikit-learn explicitly.
- Do not claim bitwise determinism for parallel or GPU baselines unless verified.
- Save simulation draws required for final figures.

## Dataset versions

- Never overwrite raw downloads.
- Store the Zenodo record ID and file checksum.
- Produce a source-to-canonical schema map.
- Record excluded intervals and their reasons.

## Computational budget

Each experiment configuration must define a low-cost smoke mode and a paper mode. Continuous integration runs smoke mode only.
