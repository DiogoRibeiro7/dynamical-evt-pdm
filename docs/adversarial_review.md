# Adversarial Scientific Review

This document records the hostile but technically fair review position used by the submission package. The generated package report remains the authoritative current artifact in `reports/submission/reviewer_report.md`.

## Fatal Flaws

1. The manuscript must not present the workflow as a new industrial theorem or broad predictive-maintenance superiority result.
2. MetroPT and MetroPT2 have too few independent failures for row-count-based inference; raw 1 Hz rows are computational scale, not independent evidence.
3. SCANIA Component X is a vehicle-level repair-risk resource and cannot be treated as a mechanistic replication of compressor event warning.
4. Dangerous-region, threshold, regime and lag choices must be selected without held-out failure leakage.
5. Regime-conditioning and declustering claims must remain finite-sample diagnostics unless supported by prospective evidence.

## Major Revisions

The first-round resolvable major issues have been addressed in code and generated artifacts:

1. Claim ledger and paper checks block unsupported claim IDs and generated-asset provenance failures.
2. Dataset reporting separates independent units from row counts.
3. Threshold, run-length, matching-tolerance, merge-gap, calibration and ablation assets are regenerated by the paper build.
4. Real-data verification and industrial diagnostic result artifacts are terminal for MetroPT, MetroPT2, SCANIA Component X, Hydraulic Systems and SECOM when local public data have been fetched and prepared.
5. The submission package copies the manuscript, supplement, sources, claim ledger, real-data matrix evidence, industrial results, reviewer report and revision matrix without redistributing raw third-party datasets.

## Further Extensions

These analyses would strengthen or broaden the paper, but they are not blockers for the current constrained claim set:

1. Additional compressor failures beyond the available MetroPT and MetroPT2 held-out events.
2. Prospective validation using the same predeclared settings before future failures occur.
3. SCANIA vehicle-level uncertainty intervals over vehicles.
4. Noise, missingness, smoothing and shifted-label stress tests.
5. Larger baseline-challenge surfaces under the same validation budget.

## Claims Kept Restricted

The manuscript and claim ledger intentionally preserve these limits:

1. Broad industrial performance beyond the evaluated evidence is not claimed.
2. Causal mechanical degradation detection is not claimed.
3. Calibration is described as a diagnostic unless prospective calibrated probabilities are available.
4. SCANIA evidence is vehicle-level operational validation, not compressor-event replication.
5. Independent evidence refers to failures, temporal blocks or vehicles, never raw seconds.

## Evidence That Would Broaden Claims

1. Prospective evidence showing improved alarm burden without materially reducing recall.
2. Bootstrap or hierarchical uncertainty over failures, days, blocks or vehicles.
3. Null experiments showing regime labels, smoothing, missingness and shifted failures do not create the apparent clustering.
4. External event datasets with enough independent failures to estimate event-level precision, recall and uncertainty.
5. A predeclared lag-selection protocol with prospective or independently held-out evaluation.
